# Retro_Clock PAC-MAN
Pac-Man Clock

ドット絵のマトリクスパネル上に現在時刻を表示し、Pac-Man とゴーストたちがその上を走り抜ける、レトロ風のデジタル時計です。純粋な HTML / CSS / JavaScript のみで動作し、ライブラリやビルド環境は不要です。

特徴





32 × 16 のドットマトリクス上に HH:MM 形式で現在時刻を表示します。



数字が変わるとき、上の行から下の行へ 1 行ずつ新しい数字へ切り替わるアニメーションを行います。



一定間隔で Pac-Man と 4 体のゴースト（blinky / pinky / inky / clyde）がパネル上を横切ります。



5 回に 1 回は特別演出になり、青い「いじけゴースト」4 体が左へ逃げ、Pac-Man が左右反転して追いかけます。



各マスに質感画像を重ねて、レトロな LED / ネオン風のにじんだ見た目を再現します。



全画面表示を切り替えるボタンを備えています。

構成ファイル





Retro Clock.html — 画面の骨組み。時計パネルと操作ボタンのコンテナを定義します。



script.js — ドット絵データ、時計描画、数字アニメーション、キャラクター演出、全画面制御などのロジック。



style.css — レイアウト、各マスの色、質感、コロンの点滅などのスタイル。



light-60.png — 各マスに敷く質感（にじみ）用の背景画像。



favicon.ico — ブラウザタブ用のアイコン（任意）。

使い方





上記のファイルをすべて同じフォルダに置きます。



Retro Clock.html を Web ブラウザで開きます。



現在時刻が表示され、自動的にキャラクター演出が始まります。



右上のボタンで全画面表示を切り替えられます。

サーバーは不要で、ファイルを直接開くだけで動作します。ただし全画面 API はブラウザによって安全なコンテキスト（HTTPS など）を要求する場合があります。

仕組み

ドットマトリクス

createPixelGrid() が、32 × 16 個の div.pixel 要素を 2 面ぶん生成します。下段（bottom）は時計の数字用、上段（top）はキャラクター用のレイヤーです。各マスは bottom-x-y / top-x-y という ID を持ちます。

ドット絵データ

pixelData 配列が、数字・コロン・各キャラクターの見た目を文字列の 2 次元グリッドとして保持します。グリッド内の 1 文字が 1 マスの色に対応します。





0 = 消灯（透明）



1 / W = 白



L = コロン



R = 赤（blinky）



P = ピンク（pinky）



C = シアン（inky）



O = オレンジ（clyde）



F = 青（いじけゴースト）



Y = 黄（Pac-Man）



B = 青（目など）

printCharToPanel() が、このグリッドを走査して各マスに対応する色クラスを割り当てます。

時刻表示と数字アニメーション

displayTimeDigits() が現在時刻を 4 桁に分解し、前回表示と比較して、変化した桁だけを animateDigitTransition() に渡します。アニメーションは 8 行ぶんを上から順に切り替えて、なめらかな数字の遷移を表現します。

キャラクター演出

countDownToGroupRelease() が一定秒ごとに releaseTheGroup() を呼び出します。通常回は Pac-Man に続いてゴースト 4 体が右へ流れます。5 回に 1 回の特別回では、いじけゴースト 4 体が左へ逃げ、そのあとを Pac-Man が左右反転して追いかけます。animateCharacter() が各キャラクターの移動とフレーム切り替えを担当します。

質感（にじみ）

各 .pixel の背景に light-60.png を敷くことで、点灯したマスにレトロな発光の質感を与えています。色そのものは background-color、質感は背景画像が担当する役割分担になっています。

主な設定値

script.js 冒頭付近の変数を変更すると、挙動を調整できます。





xWidth / yHeight — マトリクスの横・縦のマス数（32 / 16）。



yOffset — 数字を表示する縦位置のオフセット（上 4 マス空け）。



characterSpeed — キャラクター移動の速さ（ミリ秒、小さいほど速い）。



releaseDelay — キャラクター演出の発生間隔（秒）。



digitTransitionDuration — 数字が切り替わるアニメーションの所要時間（ミリ秒）。



place1 〜 place5 — 各桁とコロンの横位置。

カスタマイズ例





数字やキャラクターの見た目を変えたい場合は、pixelData 内の対応する grid を編集します。



色を変えたい場合は、style.css の .pixel-* クラスの background-color を調整します。



にじみの質感を差し替えたい場合は、light-60.png を別画像に置き換えます。

動作環境





Material Icons と Google Fonts をオンラインで読み込むため、ボタンアイコン表示にはインターネット接続が必要です。



全画面表示は、Fullscreen API に対応したブラウザで利用できます。
